heat-amortization — statistical multiplexing sandbox ?When does a fleet of spiky workloads "balance itself out"? Two things decide it: how correlated the workloads are, and how many share the fleet. Independent spikes cancel as you add workloads; a shared daily cycle stacks up no matter the scale. Inspired by the "managing heat" section of Andy Warfield's S3 post.
parameters
workload type

0% = each workload spikes on its own schedule · 100% = all spike together.

higher = rarer but taller bursts (heavier tail); lower = gentle, frequent bumps.

0% = every cycle peaks at the same hour · 100% = peaks spread around the clock.

0% = same daily swing for all · 100% = swings vary widely (some flat, some huge).
